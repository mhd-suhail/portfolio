## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example: `portfolio`).
2. Upload all files and folders in this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/portfolio/`.
